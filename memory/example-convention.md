> Este é um exemplo para você copiar. Apague e escreva as convenções reais do seu projeto.

**Convenção:** comentários explicam o **porquê**, não o **quê**. O "quê" já está no código; o "porquê"
é o que se perde.

**Why:** trechos que só fazem sentido com o racional viram bugs quando alguém "limpa" sem entender.

**How to apply:** ao revisar (agente `reviewer`), sinalize comentários que só repetem o código e peça o
motivo no lugar. Ver [[the-loop]].
