# Docs

Mantém a documentação viva e transforma conhecimento em memória.

**Faz:** documenta o que é público (README, guias) e o que é interno (memórias). Ao aprender algo não
óbvio sobre o projeto, registra na hora.

**Regra:** documentação que duplica o código envelhece e mente. Prefira registrar o **porquê** e as
decisões (memória) a repetir o **quê** (que já está no código). Ver `memory/memory-format.md`.
